Welcome to placehold.us
A quick and simple image placeholder service.

How does it work? Just put your image size after our URL and you'll get a placeholder.
Like this: https://placehold.us/350x150
You can also use it in your code, like this:
<img src="https://placehold.us/350x150">
Have fun!

Image Formats

.svg, .png, .jpg, .gif, .webp

SVG is the default. It stays sharp at any size, and you don't need an extension for it. For any other format, add an extension. It can go at the end of any part of the URL.

https://placehold.us/300.png/09f/fff
https://placehold.us/300/09f.jpg/fff
https://placehold.us/300/09f/fff.webp

For retina screens, add @2x or @3x. You get twice (or three times) the pixels with the same layout.
https://placehold.us/300x150@2x.png

Custom Text

?text=Hello+World

The default text is the image size, like "300 x 250". Put your own at the end of the URL, up to 500 characters. Spaces become +, and | starts a new line. PNG, JPG, GIF and WebP can draw English and most accented letters. For other languages, use SVG.

https://placehold.us/300?text=placehold.us+rocks!
https://placehold.us/300?text=Line+one|Line+two

Text sizes itself to fit. To pick a size in pixels, add font-size.
https://placehold.us/300?text=Big&font-size=90

Colors

background color / text color

Colors are hex codes, without the #. Three digits work too (09f is 0099ff). Colors always follow the size.
https://placehold.us/250/ffffff/000000
not
https://placehold.us/ffffff/250/000000

For no background at all, use transparent. It works in SVG, PNG, GIF and WebP. JPG has no transparency, so it gets white.
https://placehold.us/250/transparent/e8117f.png

Size

width x height

Height is optional. Leave it off and you get a square. The largest size is 3000 x 3000, or 1500 x 1500 for WebP.

Example: https://placehold.us/300
Note: Size must be the first part of the URL
